最终解决：重建一个shapeit的虚拟环境

直接创建一个虚拟环境 （Conda 的求解进程被系统“静默终止”了，只能用 mamba ，mamba 很快 ）

经验

用好 mamba

  1. conda 的 base 环境必须安装 mamba 。并且base 环境除了 conda、mamba 及其自身依赖外，不应安装任何其他软件包。
  2. base 环境中严禁混用 conda 和 mamba 。在 base 环境中，只使用 conda 来安装或更新 mamba 本身
  3. 对于你通过 conda create 或 mamba create 创建的所有其他环境（如 shapeit4），conda 和 mamba 的命令是完全等价且可互换的。可以混用，但是由于 mamba 更快，推荐统一使用 mamba 进行包的安装、更新和删除。

遇到环境问题怎么办

  1. 最好新建一个虚拟环境来解决，或者也可以尝试在一个临时环境解决。就是不要在自己的工作的主环境来弄，崩了重新来麻烦。
