CT 重采样是很常见的一种前处理技术。

重采样

基于ITK库进行CT图像重采样，通常有两种主流方式：一是直接使用底层的 ITK 库（C++或Python），二是使用其更友好的高层封装 SimpleITK（主要支持Python）。SimpleITK 接口更简洁，是实现这类任务的更常见选择。

其核心思路是：计算新的图像尺寸，使新旧图像覆盖相同的物理空间。下面以 SimpleITK 为例，详细介绍实现步骤。

💎 关键点总结

  • 物理空间不变：重采样的核心是新尺寸 = 旧尺寸 * (旧间距 / 新间距)，确保图像覆盖的物理范围不变。
  • 插值方法的选择：对CT等灰度图像，使用线性插值（sitkLinear）或B-Spline插值；对分割标签，务必使用最近邻插值（sitkNearestNeighbor）以保护标签值。
  • 保留空间信息：重采样时，除了设置Size和Spacing，还应将原始的Origin（原点）和Direction（方向）复制到新图像，确保其空间位置准确。

下采样

你的理解完全正确！重采样的核心逻辑正是：给定新的体素间距（Spacing） → 保持物理空间不变 → 自动换算出新的图像尺寸（Size）。

那么，下采样（Downsampling） 其实就是 重采样（Resampling）的一个特例。

简单来说：当“新间距”大于“旧间距”时，计算出的“新尺寸”就会小于“旧尺寸”，这个过程就是下采样。

1. 下采样在公式中的体现

论文里，他们将原始图像从 1024×1024 （假设对应某个体素间距）降为 256×256×128，这就是典型的4倍下采样。

在代码层面，有两种等效的实现思路：

  • 思路A（通过间距驱动）：如果你想让图像缩小4倍，就把新间距设置为旧间距的4倍。 [ = = = 256 ]

  • 思路B（直接指定尺寸）：在ITK中，你也可以直接通过 SetSize([256, 256, 128]) 强行指定输出尺寸。此时，ITK会自动反算出一个新的间距，使物理范围不变，这也叫下采样。

2. 严格意义上的“下采样”其实包含一步预处理（防锯齿）

在数字图像处理（尤其是深度学习）中，我们通常将“尺寸缩小”笼统地称为下采样。但在严格的信号处理理论中，直接使用插值（如线性插值）进行尺寸缩小，可能会产生“混叠伪影”（Aliasing），因为高频细节在缩小时会产生失真。

因此，教科书级别的严谨下采样流程应该是：

  1. 先低通滤波（平滑）：对原始图像进行高斯模糊（Gaussian Blur），滤除高频细节。
  2. 后重采样（抽取）：再进行间隔采样或插值缩小。

然而，在医学图像处理的实际工程中（包括这篇论文），为了简化流程并保证CT值（HU值）的物理准确性，绝大多数场景下直接使用“三线性插值（Linear Interpolation）”进行尺寸缩小就足够了。因为CT图像本身信噪比较高，且线性插值自带一定的平滑效果，能够满足后续分割模型的精度要求。

总结一句话

  • 重采样：是通用大概念（包含上采样、下采样、改变各向异性）。
  • 下采样：是重采样在 “新间距 > 旧间距” 情况下的具体应用。
  • 在ITK的实现中，不管你叫它下采样还是重采样，底层调用的都是同一个 ResampleImageFilter 滤波器，区别只在于你给它的 Spacing 或 Size 参数数值大小不同。
