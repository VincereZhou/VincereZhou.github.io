np.mean：相反效果

但是，“along an axis”这一个统一规则，在不同类型的函数上呈现出不同的效果。

比如如果采用求均值等涉及轴消除的函数，效果完全相反，例如

输出为每列的均值

关键在于：mean 是个归约函数（reduction），其计算过程为（这是 AI 的解释）：

  1. 沿 axis=0 取出切片集合：[a[0,:], a[1,:], a[2,:]]（和术语表定义一致）
  2. 对每个切片集合做归约：把这三个切片”压缩”成一个——具体是对它们逐元素求平均
  3. axis=0 这一维被消除——因为已经没有”多行”可言了，只剩”一列值”

💡 “along axis=n” 始终表示：把数组看作一串以 axis n 为索引的切片。至于操作之后 axis n 是否还存在，取决于具体操作的性质：

  • 非归约操作（flip、sort、apply_along_axis）：axis n 保留，只是切片被重新排列或各自被处理
  • 归约操作（sum、mean、max、min）：axis n 被消除，因为该方向上的多个值被”压缩”成了一个

我的理解

我看了官方文档、AI回答、及其整理的资料，我觉得都不算完全对，或者说没有概括清楚所有的情况。下面说一下我的看法，不一定全对，但是是我归纳得到的结论。

我的理解是，指定 axis=n 时，表示操作将沿着第 n 个维度进行遍历，或者说沿着轴 n 滚动。但是具体怎么个遍历方法不同函数有区别。

下面都以 axis = 0 为例。

这里其实分为3层含义（自身理解，不一定对，但是是我自己从所有 axis=n 整理的规律 ）：

  1. 非归约操作的第一种：遍历的是整个切片，就是上面的官方定义，代表函数是 np.flip 和 np.concatenate，二维数组 axis = 0 就是遍历所有行的切片，三维数组 axis = 0 就是遍历所有的二维矩阵的切片，然后改变顺序或整合

  2. 非归约操作的第二种：遍历的是单个元素，也就是沿着 0 轴遍历，提取其他轴某个固定位置的元素，得到这样一组元素的切片，然后改变顺序，代表函数就是 np.sort 。二维数组 axis = 0 ，那就是先提取列号为 0 的所有行的元素，改变顺序，然后列号为1，一直到最后一列。三维数组 axis = 0 也一样，就是先提取第二个轴和第三个轴的坐标均为0的所有行的元素。

    重新整理一下，怎么提取元素的过程，这样好理解：

    1. 固定其他轴：对于输出结果的每一个位置，它先固定除了 axis=i 之外的所有轴。

    2. 沿轴迭代：然后，它沿着 axis=i（即 axis=0，行方向）进行迭代，也就是“沿着”行的方向，从上到下取出所有元素。

  3. 归约操作：同第二种操作，也是遍历的单个元素，只是这是这类函数提取到一组单个元素的切片后，会将其计算为单个的值，因此就将 axis = 0 的形状变成了1，也就是消除了这个维度。代表函数就是 np.mean 。

这里 2 和 3 逻辑是一样的，只不过返回的数组维度不变还是降维而已。但是 1 和 2/3 从效果来说就是相反的，这就是容易让人混淆的。

另一种解释

如果一定要按照那个官方定义来解释所有函数的话，就只能这么理解了。

  1. 非归约操作的第一种：沿 axis=0 取出切片集合，对这个切片集合进行改变顺序或整合
  2. 非归约操作的第二种：沿 axis=0 取出切片集合后，提取所有切片相同位置的元素，然后在所有切片上重新组合
  3. 归约操作：沿 axis=0 取出切片集合后，将所有切片”压缩“成单个切片。做法也是提取所有切片相同位置的元素整合成单个值。

这样理解也可以。注意的点就是所有操作就是针对切片集合的处理，而不是对单个切片的处理。比如求均值，是对切片集合相同位置元素求均值，而不是对单个切片的所有元素求均值。

下面是 AI 给出的归约函数的做法的解释，AI 只给出了这类函数的解释。

归约函数怎么理解

归约操作（Reduction Operation），在 NumPy、PyTorch 等科学计算库中，指的是将一组数据通过某种聚合规则，压缩成更少的数据（通常是单个值或更小维度的张量）。

先把坐标系建立起来

对于一个 shape = (4, 3) 的二维数组：

  • axis=0（第 0 维）：长度是 4，对应行的方向——沿着这一维走，你会遍历 4 行
  • axis=1（第 1 维）：长度是 3，对应列的方向——沿着这一维走，你会遍历 3 列

核心心法：axis=k 意味着”把第 k 维干掉”

当你对一个数组执行 np.sum(arr, axis=k) 这类归约操作时，第 k 维会从结果里消失——因为这一维上的所有元素被”汇总”成一个值了。

操作 输入 shape 输出 shape 含义
a.sum(axis=0) (4, 3) (3,) 把行这一维消掉 → 得到每列的总和
a.sum(axis=1) (4, 3) (4,) 把列这一维消掉 → 得到每行的总和
a.sum() (4, 3) () 标量 把所有维度都消掉 → 总和

实跑：

验证”维度消除”：输入 (4, 3)，消掉 axis=0（长度为 4 的那维）→ 剩下 (3,)；消掉 axis=1（长度为 3 的那维）→ 剩下 (4,)。结果的 shape 就是”原 shape 去掉 axis 指定的那一位”。

用”固定其他维，沿 axis 滚动”来理解

如果你觉得”消除”太抽象，可以用另一种等价视角：axis=k 表示”沿着第 k 维的方向做运算”，也就是固定其他所有维度，只让第 k 维的索引变化。

以 a.sum(axis=0) 为例： - 固定列号 j（j 可以是 0, 1, 2） - 让行号 i 从 0 变到 3，把这 4 个数加起来 - 所以结果是一个长度为 3 的数组，每个元素是”某一列上所有行的和”

以 a.sum(axis=1) 为例： - 固定行号 i（i 可以是 0, 1, 2, 3） - 让列号 j 从 0 变到 2，把这 3 个数加起来 - 结果是一个长度为 4 的数组，每个元素是”某一行上所有列的和”

推广到三维：用你的形状推 axis

这套逻辑对 N 维数组通用。假设有个 shape = (2, 4, 3) 的三维数组：

  • axis=0：长度 2，沿着”最外层”方向 → 归约后 shape 变成 (4, 3)
  • axis=1：长度 4，沿着”中间层”方向 → 归约后 shape 变成 (2, 3)
  • axis=2：长度 3，沿着”最内层”方向 → 归约后 shape 变成 (2, 4)

记住这条规律：result.shape = 原 shape 去掉 axis 对应的那一维。

几个常见的 axis 操作场景

函数 axis=0 axis=1
np.sum 各列求和 各行求和
np.mean 各列平均值 各行平均值
np.max 各列最大值 各行最大值
np.concatenate 按行拼接（上下叠） 按列拼接（左右拼）
np.delete 删除某些行 删除某些列

注意 np.concatenate 是个特例——它不”消除”维度，而是”沿着 axis 方向连接”。但 axis 编号的含义不变：axis=0 仍是行方向，axis=1 仍是列方向。
